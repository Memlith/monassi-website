# Monassi Website Development Skill

This skill provides instructions for developing, styling, and maintaining the Monassi Website.

## Core Workflows

1. **Exploration**:
   - List contents of the workspace directory to understand the project structure.
   - Look for setup files like `package.json` to identify available scripts and dependencies.

2. **Design & Styling**:
   - Use Vanilla CSS for styling.
   - Follow modern typography and responsive design principles.
   - Avoid forbidden design tropes unless explicitly requested.

3. **Development**:
   - Run the development server with `npm run dev`.
   - Verify changes locally.

4. **Production**:
   - Build the site using `npm run build` to ensure no build errors are present.
